The app running live on a phone: it finds the cards, reads them, and highlights every set on the table.

What it is

An Android app that watches a table of SET cards through the phone's camera and highlights every valid set in real time. Nothing runs on a laptop: detection, card reading, and solving all happen on the phone at about 29 frames per second.
